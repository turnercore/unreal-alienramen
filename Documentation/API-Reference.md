# C++ API Reference (Doxygen)

The full native API reference is generated by Doxygen from `Source/` during the MkDocs build.

- When building locally, install `requirements-docs.txt`, make sure `doxygen` is on `PATH`, and run `python -m mkdocs serve`.
- On CI (`docs` workflow), Doxygen runs automatically and output is placed under `site/doxygen/`.

Once generated, browse the HTML at [doxygen/index.html](/unreal-alienramen/doxygen/index.html).
