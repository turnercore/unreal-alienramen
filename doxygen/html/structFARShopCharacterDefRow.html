Detailed Description

Data table row for shop-playable characters (DT_Characters / DT_ShopCharacters).

Speaker/customer links are intentionally component-driven on the spawned pawn Blueprint (UParleySpeakerComponent, UARCustomerComponent).

Identity tag contract:

  • CharacterTag (Shop.Character.*)
  • CustomerTag (Shop.Customer.*)
  • SpeakerTag (Parley.Speaker.*) These tags should mirror only by the first segment under the root (for example Brother in Shop.Character.Brother.*), while deeper subleafs may diverge per-system.
